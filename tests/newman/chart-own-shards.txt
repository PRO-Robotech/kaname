# ПЛАН ШАРДОВ ЗАДАНИЯ `chart-own` (kaname#848): шард — строка «<шард>: <набор> …».
#
# Каждый шард гоняется на СВОЁМ стенде со всеми посевами задания, поэтому набор
# не видит состояния, оставленного набором другого шарда. Порядок наборов ВНУТРИ
# шарда — прежний относительный порядок единого вызова, и он несущий: вход
# первым, церемония после входа (отказ читается после отказа входа), ключи
# доступа после церемонии; регистрация и подтверждение адреса до смены адреса.
#
# Второй фактор — ОДИН в шарде: он заводит фактор человеку посева и снимает его
# своим последним кейсом; прежде он шёл последним из наборов этого человека,
# теперь человека посева на его стенде не трогает никто, кроме него самого.
#
# Вселенная выводится (`scripts/shard_plan.py`, `universe`): набор, читающий
# `loginLaneBaseUrl`, не попавший сюда, роняет прогонщик каждого шарда с именем.
#
