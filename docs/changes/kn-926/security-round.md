### Находки

- **926-1 · средняя.** После сужения роли выдачи, которые параллельно материализует
  аддитивный форвард, могут сохранить пообъектный доступ уровня яруса по прежнему
  набору глаголов. Окно ограничено следующим полным проходом сведения выдачи, то
  есть обходом всех выдач с правилами, и его длительность растёт с установкой.
  Доступ глаголом (`v_*`) сужается сразу; задержка касается проверок уровня яруса.
- **926-2 · высокая.** После снятия роли модуля выдачи этой роли сохраняют
  пообъектный доступ уровня яруса на объектах, материализованных до снятия. Сведение
  его не снимает; снимает лишь отзыв, удаление или истечение самой выдачи. Это
  расходится с приёмкой снятия (§2.4: выдача на снятой роли не даёт ничего).
