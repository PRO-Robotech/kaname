# Провайдер Terraform: ресурсы IAM

Провайдер `kacho` один на всю платформу — установка и настройка описаны на
странице «Провайдер Terraform» в документации VPC. Здесь только то,
что относится к IAM.

## Ресурсы

| Ресурс | Что описывает | Область |
|---|---|---|
| `kacho_iam_project` | Проект — область, внутри которой живут ресурсы платформы | аккаунт |
| `kacho_iam_group` | Группа субъектов | аккаунт |
| `kacho_iam_service_account` | Служебная учётка — принципал машинного доступа | аккаунт |

Все три — **аккаунтные**: они принимают `account_id`, а не `project_id`. Служебная учётка
тоже: сузить её до проекта можно только выдачей прав, а не местом заведения.

Типовую связку описывает [модуль `iam-project`](module-iam-project).

## Использование

```hcl
resource "kacho_iam_project" "prod" {
  account_id  = var.account_id
  name        = "production"
  description = "боевой контур"
  labels      = { env = "prod" }
}

resource "kacho_iam_group" "admins" {
  account_id = var.account_id
  name       = "prod-admins"
}

resource "kacho_iam_service_account" "ci" {
  account_id = var.account_id
  name       = "ci-deployer"
}
```

## Права выдаются группе, а не перечислением людей

Право, которое получает больше одного принципала **или** чей состав получателей может
измениться, выдаётся **группе**; люди и служебные учётки в неё добавляются. Причина —
цена изменения состава: снять одного из группы это одна запись членства, снять одного из
перечисления — снятие прав по всем объектам роли.

Перечисление субъектов законно ровно для одного случая: получатель один и меняться не
будет (служебная учётка модуля, чья личность и есть предмет выдачи).

## Что мешает удалению

Край отказывается удалять ресурс, на который ещё ссылаются. Провайдер называет причину
заранее, в самом отказе, — иначе она выясняется перебором:

| Ресурс | Что удерживает |
|---|---|
| Проект | Пользовательская роль, определённая в этом проекте: ссылка защищена на уровне хранилища |
| Группа | Действующие выдачи прав на группу. Члены удалению **не** мешают — членство снимается вместе с ней |
| Служебная учётка | Действующие выдачи прав и членство в группах. Ключи учётки **не** мешают |

## Имя обязательно, хотя платформа его не требует

`name` — единственный способ найти уже созданный ресурс, если ответ на создание не дошёл.
Без имени повтор создал бы дубль, поэтому провайдер требует имя строже, чем край.

## Ответ «не найдено» не означает «удалено»

Край отвечает на запрос к недоступному ресурсу дословно так же, как на запрос к
несуществующему. Провайдер не снимает ресурс из состояния по одному такому ответу: он
подтверждает отсутствие отдельным запросом к списку и **останавливается**, если подтвердить
нечем. Полная таблица исходов — на
странице «Провайдер Terraform» в документации VPC.

## Импорт

```bash
tofu import kacho_iam_project.prod          prj...
tofu import kacho_iam_group.admins          grp...
tofu import kacho_iam_service_account.ci    sva...
```

Формат проверяется по общему каталогу префиксов платформы до обращения к краю.
